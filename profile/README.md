## Open source

What we publish can be read, run and criticized. Every figure we publish states what was measured, where and when.

| Repository | What it is | Status |
|---|---|---|
| [cpp-cache](https://github.com/simylresearch/cpp-cache) | Concurrent in-memory cache for C++20 processes, with a single-flight protocol against request stampedes. | C++20 · MIT license · Promela/SPIN formal model included in the repository |
| [gateway_cache](https://github.com/simylresearch/gateway_cache) | The Go implementation of the same cache protocol, designed for API gateways. | Go · MIT license · published in 2020 · in production since then on the sports data platform of Genius Sports |
| [Aleph-w](https://github.com/simylresearch/Aleph-w) | Data structures and algorithms library in C++ with an emphasis on functional programming. | C++ · MIT license · under active development |
| [go-breaker](https://github.com/simylresearch/go-breaker) | Circuit breaker for Go services: it trips on memory and latency thresholds, with trend analysis and OpsGenie alerts. | Go · MIT license · tests included |
| [uconv](https://github.com/simylresearch/uconv) | Units and physical-quantities library in C++20, with strongly typed quantities at compile time and a DSL to define units and conversions. | C++20 · GPL-3.0 license · continuous integration |
| [back-pvt](https://github.com/simylresearch/back-pvt) | PVT characterization of fluids: physical properties as a function of pressure and temperature, with its test suite. | C++ · GPL-3.0 license · tests included |
| [simyl-benchmarks](https://github.com/simylresearch/simyl-benchmarks) | Reproducible benchmark harness for `cpp-cache` and `gateway_cache`: the same protocol in Go and C++20, with raw data and the results of October 2026. | Go · C++20 · MIT license · results published |

`simyl-benchmarks` is the company's own repository; the other repositories are the company's copies of projects maintained by members of our team, and each one links to its original. Licenses, credits and history are preserved.

Results and method: [Benchmarks](https://simylresearch.com/en/benchmarks/) and [How we measure](https://simylresearch.com/en/method/), with downloadable templates.

## How we work

- Diagnosis first: we start from measurements of the current system, not from assumptions.
- One change at a time, measured under the same conditions before and after.
- Results are delivered with the conditions under which they were obtained: hardware, load, configuration and date.

### Cómo trabajamos

- Primero el diagnóstico: partimos de mediciones del sistema actual, no de suposiciones.
- Un cambio a la vez, medido en las mismas condiciones antes y después.
- Entregamos los resultados con las condiciones en que se obtuvieron: hardware, carga, configuración y fecha.
